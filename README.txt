DEPLOY DI RAILWAY
1. Upload semua isi folder ini ke repo GitHub.
2. Railway > New Project > Deploy from GitHub repo.
3. Variables: ADMIN_USER=malzx, ADMIN_PASS=(password), DATA_DIR=/data
4. Settings > Volumes: buat volume, mount path /data (biar data admin tidak hilang saat redeploy).
5. Settings > Networking > Custom Domain: malzxploit-official.my.id
